# odoo-addons

Free Odoo addons by Bohdan Holoborodko, published on the
[Odoo Apps Store](https://apps.odoo.com/apps/modules/browse?search=holoborodko).
One branch per Odoo version: **16.0** · [17.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/17.0) · [18.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/18.0) · [19.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/19.0).

## Available addons

addon | version | summary | Apps Store
--- | --- | --- | ---
[customer_tags_sale_order](customer_tags_sale_order/) | 16.0.1.0.1 | Show customer tags in sale order | [16.0](https://apps.odoo.com/apps/modules/16.0/customer_tags_sale_order/)

`customer_tags_sale_order` was published as `partner_tags_sale_order` for
Odoo 12.0–15.0: [12.0](https://apps.odoo.com/apps/modules/12.0/partner_tags_sale_order/) · [13.0](https://apps.odoo.com/apps/modules/13.0/partner_tags_sale_order/) · [14.0](https://apps.odoo.com/apps/modules/14.0/partner_tags_sale_order/) · [15.0](https://apps.odoo.com/apps/modules/15.0/partner_tags_sale_order/).

## Installation

Download the addon from the Apps Store, or clone branch `16.0` and add the
checkout directory to the `addons_path` of an Odoo 16.0 instance. Then update
the apps list and install the addon from Apps.
