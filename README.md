# odoo-addons

Free Odoo addons by Bohdan Holoborodko, published on the
[Odoo Apps Store](https://apps.odoo.com/apps/modules/browse?search=holoborodko).
One branch per Odoo version: [16.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/16.0) · [17.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/17.0) · [18.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/18.0) · [19.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/19.0) · **20.0**.

## Available addons

addon | version | summary | Apps Store
--- | --- | --- | ---
[cron_category](cron_category/) | 20.0.1.1.0 | Add categories to scheduled actions for better organization | [20.0](https://apps.odoo.com/apps/modules/20.0/cron_category/)

## Installation

Download the addon from the Apps Store, or clone branch `20.0` and add the
checkout directory to the `addons_path` of an Odoo 20.0 instance. Then update
the apps list and install the addon from Apps.
