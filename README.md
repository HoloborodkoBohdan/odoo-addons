# odoo-addons

Free Odoo addons by Bohdan Holoborodko, published on the
[Odoo Apps Store](https://apps.odoo.com/apps/modules/browse?search=holoborodko).
One branch per Odoo version: [16.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/16.0) · [17.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/17.0) · [18.0](https://github.com/HoloborodkoBohdan/odoo-addons/tree/18.0) · **19.0**.

## Available addons

addon | version | summary | Apps Store
--- | --- | --- | ---
[cron_category](cron_category/) | 19.0.1.0.0 | Add categories to scheduled actions for better organization | [19.0](https://apps.odoo.com/apps/modules/19.0/cron_category/)
[customer_tags_sale_order](customer_tags_sale_order/) | 19.0.1.0.0 | Show customer tags in sale order | [19.0](https://apps.odoo.com/apps/modules/19.0/customer_tags_sale_order/)
[form_group_toggle](form_group_toggle/) | 19.0.1.0.0 | Collapse and expand groups in Odoo form views | [19.0](https://apps.odoo.com/apps/modules/19.0/form_group_toggle/)

`customer_tags_sale_order` was published as `partner_tags_sale_order` for
Odoo 12.0–15.0: [12.0](https://apps.odoo.com/apps/modules/12.0/partner_tags_sale_order/) · [13.0](https://apps.odoo.com/apps/modules/13.0/partner_tags_sale_order/) · [14.0](https://apps.odoo.com/apps/modules/14.0/partner_tags_sale_order/) · [15.0](https://apps.odoo.com/apps/modules/15.0/partner_tags_sale_order/).

## Installation

Download the addon from the Apps Store, or clone branch `19.0` and add the
checkout directory to the `addons_path` of an Odoo 19.0 instance. Then update
the apps list and install the addon from Apps.
