To use this module:

1. Install the module
2. Go to **Settings > Technical > Automation > Scheduled Actions Categories**
3. Create new categories for organizing your scheduled actions
4. Go to **Settings > Technical > Automation > Scheduled Actions**
5. Assign categories to your cron jobs using the "Category" field

Managing Categories
~~~~~~~~~~~~~~~~~~~

* Navigate to **Settings > Technical > Automation > Scheduled Actions Categories**
* Click "Create" to add a new category
* Enter a unique name for the category
* Save the category

Assigning Categories to Cron Jobs
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* Open any scheduled action
* Select a category from the "Category" dropdown
* Save the scheduled action
* All cron jobs without a category are automatically assigned to "Uncategorized"

Filtering by Category
~~~~~~~~~~~~~~~~~~~~~

* The Scheduled Actions list has a panel on the left with every category and
  the number of scheduled actions in it; click a category to show only its
  actions, or *All* to show them all again
* To group instead, open the search options and pick *Group By > Category*
