Scheduled Actions Category (Cron Category)

Organize scheduled actions with categories

Features

  • Create custom categories for organizing cron jobs
  • Assign categories to scheduled actions
  • Filter and group scheduled actions by category
  • Default "Uncategorized" category for all cron jobs
  • Simple and intuitive interface
  • Better organization of scheduled tasks

Usage

Creating Categories

  1. Go to Settings > Technical > Automation > Scheduled Actions Categories
  2. Click "Create" to add a new category
  3. Enter a unique name for the category
  4. Save the category

Assigning Categories

  1. Open any scheduled action
  2. Select a category from the "Category" dropdown
  3. Save the scheduled action

Filtering by Category

In the Scheduled Actions list view, use the "Group By" filter and select "Category" to group all cron jobs by their categories.

Benefits

  • Better Organization: Group related scheduled actions together
  • Easy Management: Quickly find and manage specific types of cron jobs
  • Team Collaboration: Clear categorization helps teams understand scheduled tasks
  • Clean Structure: Maintain organized automation workflows

Technical Details

  • New model: ir.cron.category with unique name constraint
  • Extends ir.cron model with category_id field
  • Default "Uncategorized" category created on installation
  • Group by category filter in scheduled actions view
