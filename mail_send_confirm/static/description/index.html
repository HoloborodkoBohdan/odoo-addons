Chatter Send Confirmation

Ask for confirmation before a chatter message is emailed to customers, and show exactly who will receive it.

Odoo 19.0 Community & Enterprise AGPL-3

The problem

In the chatter, Send message emails the message to the followers of the record, while Log note keeps it internal. Odoo sends at once, without asking, so a note meant for colleagues sometimes reaches the customer. This module adds one step: when a message is about to be emailed to someone outside the company, a dialog lists the recipients and waits for Send or Cancel.

Highlights

Who gets the email

The dialog lists the name and email address of every external recipient.

Computed like Odoo does

The server runs the notification step of posting without posting anything.

Button and keyboard

The Send button, Ctrl+Enter and the full composer all go through it.

Quiet otherwise

No dialog for log notes, nor when only internal users are notified.

One setting

Per company: external recipients, any email recipient, or never.

Nothing lost

Cancel closes the dialog and keeps the message in the composer.

Who counts as a recipient

Right before the message is posted, the module asks the server who would be notified by email, with the same data the chatter is about to send:

  • followers subscribed to Discussions
  • suggested and added recipients
  • mentioned contacts
  • email addresses that do not have a contact yet

The author and archived contacts are left out, as Odoo does.

Who is external

A contact without an internal user: customers, vendors and portal users. Internal users who are notified in Odoo are never counted; internal users who get their notifications by email are counted only with the Any email recipient setting.

How to use

  1. Install Chatter Send Confirmation from Apps.
  2. Optionally go to Settings › General Settings › Emails › Confirm Emailed Messages and choose when to ask: External recipients (default), Any email recipient or Never.
  3. On any record with a chatter, click Send message, write and click Send (or press Ctrl+Enter).
  4. If the message will be emailed to external contacts, check the list and click Send, or Cancel to go back to the message.

Not covered: the Send by email buttons of documents (quotations, invoices, …), which are meant to email the customer, scheduled messages and edited messages.

Technical details

  • Depends on: mail.
  • Patches the chatter composer (Composer.sendMessage) and the full composer form (mail.compose.message, button Send).
  • Adds a read-only JSON route /mail_send_confirm/recipients and the method mail_send_confirm_get_recipients on mail.compose.message; both reuse mail.thread._notify_get_recipients on a message kept in memory.
  • Adds the field mail_send_confirm_mode on companies, shown in General Settings; it is set to External recipients on install and removed on uninstall.
  • One extra request to the server per message sent from the chatter, none for log notes.
